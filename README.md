# Naresh V - Portfolio

A modern, responsive portfolio website showcasing my work as a Machine Learning Engineer.

## 🌟 Features

- **Responsive Design**: Fully responsive across all devices
- **Smooth Animations**: AOS (Animate On Scroll) library for engaging animations
- **Particle Background**: Interactive particle.js background in hero section
- **Modern UI**: Purple-blue gradient theme with smooth transitions
- **Sections**:
  - Hero with typing animation
  - About Me with education
  - Work Experience timeline
  - Skills showcase with animated progress bars
  - Projects portfolio
  - Achievements & Certifications
  - Contact form

## 🎨 Color Scheme

- Primary: Purple (#6366f1)

## 🚀 How to Use

1. Open `index.html` in a web browser
2. Or host it on GitHub Pages:
   - Go to repository settings
   - Navigate to Pages
   - Select main branch
   - Your site will be live at: `https://nareshv-dev.github.io/naresh-portfolio/`

## 📝 Customization

To customize the portfolio:

1. **Update Personal Info**: Edit the content in `index.html`
2. **Change Colors**: Modify CSS variables in `assets/css/style.css` (`:root` section)
3. **Add Projects**: Update the `projects` array in `assets/css/main.js`
4. **Update Skills**: Modify the `skills` array in `assets/css/main.js`
5. **Add Images**: Replace placeholder images in `assets/images/`
